# Product model

## Boundary

**Personal cost control is free. Shared cost governance is commercial. Institutional governance is enterprise.**

### Free / OSS

A single user should receive the complete interesting technical system:

- local budgets and sub-budgets
- arbitrary periods
- rollover/banking/borrowing
- provider integrations
- accounting and enforcement
- dashboard and exports
- model/provider/workload visibility

Do not intentionally cripple the individual edition.

### Teams — later

Intended to be inexpensive enough that adoption is nearly frictionless. Product ideas include:

- shared budgets
- multiple principals/users
- central ledger
- shared dashboard
- allocations by person/team/project
- lightweight permissions
- alerts/reporting

Indicative product discussion: roughly $1/user/month or $10/user/year. This is not an implementation requirement or a billing system specification.

### Enterprise — later

- SSO/OIDC/SAML
- SCIM
- RBAC
- organization hierarchy
- multi-account / multi-project governance
- policy inheritance
- approvals
- audit/retention
- chargeback/showback
- private deployment
- support/SLA/compliance needs
